# MediSync

MediSync is a medication organization and reminder tool designed to help users track medicines, understand when to take them, and receive timely reminders based on their medication schedule and conditions.

## Overview

MediSync helps individuals stay consistent with their medication routine by making it easier to:

- record and manage medications
- review medication details
- receive reminders for scheduled doses
- track conditions such as before sleep, after food, and other usage instructions
- maintain a more organized personal health routine

## Features

- Add and record medications
- Edit medication details
- Set and receive reminders
- Track pre-medication conditions such as before sleep, after food, and similar instructions
- Support daily medication management in a simple user experience

## Why MediSync?

Medication adherence is easier when reminders and medication details are organized in one place. MediSync aims to provide a practical, user-friendly way to manage personal medication routines and reduce missed doses.
